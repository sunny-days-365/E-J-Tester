# 🗾 EJTester — 英語・日本語 単語テスト ＆ 単語帳エディタ

Python (tkinter) 製の英語・日本語単語学習ツールです。  
**単語テスト**と**単語帳エディタ**が 1 つのウィンドウに統合されています。

---

## ファイル構成

```
EJTester/
├── main.py          # 統合アプリ（起動エントリポイント）★推奨
├── ui.py            # 単語テスト UI（テスト画面群）
├── word_editor.py   # 単語帳エディタ UI
├── tester.py        # CLI版（コマンドライン）
├── EJTester.bat     # ダブルクリックで起動（Windows）
├── vocabulary.csv   # 単語データ
└── README.md        # このファイル
```

---

## 起動方法

### 統合アプリ（推奨）
```bash
python main.py
```
または `EJTester.bat` をダブルクリック。

### 単語テストのみ
```bash
python ui.py
```

### 単語帳エディタのみ
```bash
python word_editor.py
```

### CLI版（コマンドライン）
```bash
python tester.py
```

## 機能一覧

### 🗾 単語テスト

| 機能 | 説明 |
|------|------|
| **出題モード 5 種** | 日本語→英語（4択）/ 日本語→英語（記述）/ 英語→日本語（記述）/ ローマ字→日本語（4択）/ ランダム混合 |
| **番号範囲フィルタ** | 1〜100、101〜200 … と 100 語単位で出題範囲を選択可能（単語が増えると自動で追加） |
| **品詞フィルタ** | 名詞・動詞・形容詞などで絞り込んで出題 |
| **問題数の設定** | ランダムモード時に 1 問〜全単語数まで自由に設定 |
| **進捗バー** | 残り問題数・正解数をリアルタイム表示 |
| **結果レポート** | 正解率と間違えた単語の一覧を表示 |
| **間違えた単語の再テスト** | 結果画面から間違えた単語だけを即座に再テスト |
| **フラッシュカード** | 単語をカード形式でめくって自習 |
| **単語一覧** | 全単語を一覧表示・検索・ソート可能 |

### 📝 単語帳エディタ

| 機能 | 説明 |
|------|------|
| **新規追加** | 入力フォームで 1 語ずつ追加。複数フォームを同時表示して一括保存も可能 |
| **一括テキスト入力** | 辞書コピペ形式のテキストを貼り付けて「🔄 フォーマット変換」→「💾 CSV に保存」で一括登録 |
| **一覧・編集** | 全単語を Treeview で一覧表示。ダブルクリックで編集、複数行を選択して削除 |
| **番号整理** | 削除等で生じた番号の欠番を 1 から振り直し |
| **検索・ソート** | キーワード検索・列ヘッダークリックでソート |

### 🔄 連携機能

単語帳エディタで保存すると、**単語テスト側の単語リストも即座に更新**されます（アプリ再起動不要）。

## 一括テキスト入力のフォーマット

### フォーマット A：辞書コピペ形式（自動変換対応）

辞書等からコピーした以下のような複数行テキストをそのまま貼り付け、「🔄 フォーマット変換」を押すと CSV 形式に自動変換されます。

```
201
居る
iru
いる

Verb, Ichidan verb, Intransitive verb    to be, to have
207
いつ
itsu
Pronoun    when
```

### フォーマット B：CSV 1 行形式（直接入力）

```
食べる,taberu,たべる,"Verb, Ichidan verb",to eat; to consume
猫,neko,ねこ,Noun,cat
```

> **フィールド順**: 日本語, ローマ字, かな, 品詞, 意味  
> `かな` は省略可（4 フィールドでも OK）。品詞にカンマが含まれる場合は `"` で囲む。

## 単語データ形式 (vocabulary.csv)

| カラム    | 説明               | 必須 |
|-----------|--------------------|------|
| `#`       | 番号               | ✅   |
| `ごい`    | 漢字・カタカナ表記 | ✅   |
| `ローマ字`| ローマ字読み       | ✅   |
| `かな`    | ひらがな・カタカナ |      |
| `Type`    | 品詞               | ✅   |
| `Meaning` | 英語の意味（`;` で複数可） | ✅   |

## 動作環境

- **Python 3.10 以上**（標準ライブラリのみ使用・外部パッケージ不要）
- Windows 推奨（`EJTester.bat` で簡単起動）
- macOS / Linux でも `python main.py` で動作します
