# 🗾 EJTester — 英語・日本語 単語テストプログラム

## ファイル構成

```
EJTester/
├── ui.py            # GUIメインプログラム（tkinter）★推奨
├── tester.py        # CLIプログラム（コマンドライン版）
├── EJTester.bat     # ダブルクリックで起動（Windows）
├── vocabulary.csv   # 単語データ
└── README.md        # このファイル
```

## 使い方

### GUI版（推奨）
```bash
python ui.py
```
または `EJTester.bat` をダブルクリック。

### CLI版（コマンドライン）
```bash
python tester.py
```

## 単語データ形式 (vocabulary.csv)

| カラム   | 説明               |
|----------|--------------------|
| `#`      | 番号               |
| `ごい`   | 漢字・カタカナ表記 |
| `ローマ字`| ローマ字読み       |
| `かな`   | ひらがな・カタカナ |
| `Type`   | 品詞               |
| `Meaning`| 英語の意味         |

単語を追加する場合は `vocabulary.csv` に行を追加するだけで自動反映されます。

## 出題モード

| モード | 問題の形式                              |
|--------|-----------------------------------------|
| 1      | 日本語 → 英語（4択）                   |
| 2      | 日本語 → 英語（記述）                  |
| 3      | 英語 → 日本語（記述）                  |
| 4      | ローマ字 → 日本語（4択）               |
| 5      | ランダム（全モード混合）               |

## 機能

- **品詞フィルタ**: 名詞・動詞・形容詞などで絞り込んで出題可能
- **問題数の設定**: 1問〜全単語数まで自由に設定
- **進捗バー**: 残り問題数・正解数をリアルタイム表示
- **結果レポート**: 終了後に正解率と間違えた単語の一覧を表示
- **拡張性**: `vocabulary.csv` に行を追加するだけで単語が増やせる

## 動作環境

- Python 3.10 以上（標準ライブラリのみ使用）
